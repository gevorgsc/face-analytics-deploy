# Face Analytics deployment

Use [PROJECT_AND_INSTALLATION_HY.md](../PROJECT_AND_INSTALLATION_HY.md) for the current
complete installation procedure. This migration includes Linux HCNetSDK .so files,
CPU face models and the served frontend as release assets.

Run the setup/download tool and file verification before building compose.yml.
Default ports are 8081 (UI) and 127.0.0.1:8001 (backend). New local credentials are
generated and a new installation-bound license is required. The source installation's
records, credentials and private issuer keys are not part of the public package.
